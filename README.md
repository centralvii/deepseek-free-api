# Multi-LLM Web API Proxy & Interactive CLI

Асинхронный сервис на FastAPI и интерактивная консоль для прямого взаимодействия с веб-интерфейсами ведущих нейросетей (**DeepSeek**, **Qwen**, **GLM**) без использования платных API-ключей.

## Поддерживаемые провайдеры и модели

### 1. 🤖 DeepSeek
- **`deepseek-v4-pro`**: Флагман 1.6T MoE (49B active) для сложного кодинга и математики.
- **`deepseek-v4-flash`**: Сверхбыстрая 284B MoE модель.
- **`deepseek-v4-flash-vision-exp`**: Мультимодальная модель с анализом изображений.
- **`deepseek-reasoner`**: DeepSeek-R1 с выводом пошаговых рассуждений.
- **`deepseek-chat`**: Универсальный DeepSeek-V3.
- **`deepseek-search`**: Поиск в реальном времени.

### 2. ⚡ Qwen (Alibaba)
- **`qwen-3.8`**: Флагманская модель Qwen 3-го поколения.
- **`qwen-3.8-coder`**: Передовая модель для сложных пайплайнов разработки ПО и рефакторинга.
- **`qwen-3-max`**: Модель максимальной интеллектуальной мощности.
- **`qwen-3-plus`**: Сбалансированный быстрый ассистент.
- **`qwen-3-flash`**: Мгновенный ответ с минимальной задержкой.

### 3. 🧠 GLM (Zhipu AI)
- **`glm-5.3`**: Новейший флагман GLM 5.3.
- **`glm-5-pro`**: Профессиональная модель глубоких рассуждений.
- **`glm-5-coder`**: Специализированная модель для разработки, код-ревью и тестирования.
- **`glm-5-flash`**: Zero-Latency легковесная модель.

---

## Возможности

- 🚀 **Zero-API-Key:** Работает напрямую через сессионные токены веб-интерфейсов.
- ⚡ **Встроенный PoW:** Автоматическое решение задач `DeepSeekHashV1` через WASM (<50мс).
- 🧠 **Thinking Stream:** Передача цепочки рассуждений для R1, Qwen и GLM.
- 🔄 **OpenAI & Anthropic Совместимость:** Эндпоинты `/v1/chat/completions` и `/v1/messages` с автоматическим роутингом моделей и поддержкой Tool Use для AI-агентов (Cline, Roo Code, Cursor, Aider).
- 💻 **Интерактивная консоль:** Консольный клиент `python cli.py` с автодополнением по Tab и командой `/provider`.

## Быстрый старт

### 1. Установка
```bash
pip install -r requirements.txt
```

### 2. Запуск консоли
```bash
python cli.py
```
Команды в консоли:
- `/provider <deepseek | qwen | glm>` — переключить провайдера
- `/model <название>` — переключить модель
- `/token [provider] <токен>` — установить токен
- `/think on|off|show|hide` — настроить отображение рассуждений
- `/search on|off` — включить/выключить веб-поиск

### 3. Запуск сервера API
```bash
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```
Swagger UI: http://localhost:8000/docs
